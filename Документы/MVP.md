# MVP

Эдакий пинтерест с задачами.
Показываются математические задачи, пользователь их листает, закидывает в "мешок" понравившиеся.
Чуть позже он их решает или можно решить сразу.
За решение задач получает ачивки, и формирует статистику по решениям.
Можно делиться своими мешками, и смотреть кто с какой скоростью и как решил задачи из мешка.
Можно задавать фон для задач и мешков. Можно указывать сколько задач случайным образом отдать ученику.

Мешок - Ларец
Ученик - Любознай
Преподаватель - Ведун
Задачи - Испытания

## Главная ценность
- Легко и весело решать задачи:
- легко находить подходящие
- легко познавать задачи
- видеть взаимосвязи
- собирать "приборы"?
- классная рекомендательная система?
