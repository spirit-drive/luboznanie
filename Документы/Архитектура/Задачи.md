# Задачи

Задачами может быть любой интерактив
У каждой задачи есть параметры оценки (таксономия Блума, когнитивная нагрузка и тд)
А вот исполнение может быть разным:
- математическая задача с решениями, подсказками
- задача по русскому языку
  - морфология слов
  - исправление ошибок в тексте
- Задача по программированию
  - Поиск ошибок
  - написание функции
  - создание компонента
  - Создание проекта
