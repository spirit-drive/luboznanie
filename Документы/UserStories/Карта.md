# Карта

## Прохождение сюжетной карты

- Открыл карту
- Видно ограниченное кол-во поинтов
- Решение поинтов открывает связанные поинты
- Некоторые поинты заблокированы к открытию (нужно выполнить условие:)
  - Заплатить очки
  - Иметь артефакт/передать артефакт
  - решить другой поинт
- Освоить поинт
  - Решить задачу
- Переосвоить поинт
  - Поинты можно перезахватывать, чтобы
    - блокировать оппонента
    - Получать ресурсы
- Укрепить поинт
  - Чтобы оппонент не мог перезахватить
- Построить дорогу
  - Чтобы захватить поинт
  - Стоимость строительства зависит от расстояния
- Построить поинт
  - Чтобы подобраться ближе к поинтам противника
- Собрать технологию
  - Строительства поинтов
  - Строительства дорог
  - Тепепортации
  - Увеличения стоимости
  - Укреплений
  - Разрушений дорог
  - Разрушений поинтов
- Режимы игры
  - Каждый против каждого
    - Один поинт принадлежит одному игроку
  - Совместный
    - Каждый поинт может принадлежать каждому
  - Командный
    - Каждый поинт принадлежит одной команде
- Игра пошаговая
  - Есть кнопка "след ход"
  - Каждый ход 
    - ресурсные поинты приносят ресурс
    - появляется возможность заработать дополнительные очки с помощью решения задач
    - обнуляются возможности строительства и тд

## Освоение справочной карты

- Открыл карту
- Нашел в поиске нужную тему
- прочитал лекцию, задал вопросы, решил задачи
- Поинт отмечен решенным

## Разработка карты

Включает несколько задач:

- Выбрал тип (справочная/игровая)
- Расположение поинтов
  - Название
  - Награда
  - Элемент (задачи/лекция/карта)
- Элементы ландшафта
  - Интерактив
    - С поинтом
    - Без поинта
  - Расположение 
    - z-index
    - x,y
  - Взаимосвязь
    - расположение
    - Блокировка/Разблокировка
    - Награда
    - Удаление/появление
- Визуальные элементы
  - Расположение (z-index)
  - Интерактив
    - Со свойствами
    - Без свойств
- Земля (текстура земли, возможно анимированная)
- Взаимосвязи
  - Прямые
  - Изогнутые

### Служебные
- сетка
- Занимаемость элементами
- список элементов
  - ландшафта
  - Интерактивных
- Создание поинтов
