# Решение задачи

- Открываешь задачу.
- Видно версию, автора, название, науку, теги, картинку
- [Время фиксируется]

## Открытие подсказок/решений/Ответов
Выпадает список с:
- названием
- ценностью
- кнопкой "открыть"

## Создание решения
- Нажимаешь на первый шаг
- автоматически добавляется второй шаг
- открывается меню с редактированием ввода. В меню:
  - форматирование текста
  - математические формулы
  - переход к
    - следующему шагу
    - выбор решения в качестве ответа
    - пояснить
- Напротив каждого шага есть "вернуться и начать от", а напротив последнего шага "это ответ"

## Ввод ответа
- Щелкаешь на поле ввода ответа
- Открывается меню с математическими формулами
- Вводишь ответ/выбираешь из списка
- [Нажимаешь кнопку - это ответ]
- [Обновление компонента]
  - Успех
    - Отображается время решения
    - Прочие решения
    - Прочие ответы
    - Подсказки
    - Похожие задачи
    - Прогресс
      - Подвиги (ачивки)
      - Уровень освоения темы
  - Ошибка
    - оспорить
    - [Решить еще раз (если доступно)]
  - В обоих случаях
    - объяснить с помощью ИИ (платно)
  
# Создание задачи

## Общее
- выбираешь науку
- вводишь название 
- вводишь вариант
- Тип задачи
  - Решить
  - Создать (задачу)
- выбираешь теги
  - таксономия Блума
  - науки/области/темы
  - контекст
  - когнитивная нагрузка
- вставляешь картинку

## ИИ Генерация
- ввел условие задачи
- нажал сгенерировать задачу с помощью ИИ (платно)
- проверил
- отправил на проверку
- просмотрел - отредактировал - просмотрел
- сохранил

## Ручной прямой ввод
- ввел условие задачи
- ввел решение
- ввел ответ
- добавил подсказки
- добавил варианты
- установил переменные [прямо в тексте]
- отправил на проверку
- просмотрел - отредактировал - просмотрел
- сохранил

## Ручной обратный ввод
- обратный ввод
- ввел ответ
- ввел решение
- ввел условие задачи
- добавил подсказки
- добавил варианты
- установил переменные [прямо в тексте]
- отправил на проверку
- просмотрел - отредактировал - просмотрел
- сохранил

## Предпросмотр задачи
- Нажал предпросмотр
- Открылась задача
- Без проблем можно открыть подсказки/решения/ответ
- Нажал кнопку "перегенерировать" или конпку "следующий вариант"
- Перед сохранением происходит проверка
- В случае успеха уведомление "Ошибок нет, сохраняю"
- В случае ошибки Открывается отчет о проверке

## Проверка задачи
- Нажал проверить задачу
- Произошла генерация и открылся отчет
- В отчете показаны как успешные так и ошибочные генерации
- С помошью стрелок можно быстро пробежаться по списку, стрелки прилипают к верху экрана

## Ответы

### Ответ с вариантами 
- по умолчанию 2 варианта ответа, максимум 10
- Можно добавлять/удалять варианты

### Ответ выражение
Ответом является математическое выражение
Можно указывать несколько вариантов ответов (значок "несколько ответов")

### Ответы с открытым текстом

В ответах можно выбрать общий тип: "Своими словами"

- Вводим какой результат должен показать ученик
- Вводим уровень помощи ученику (дружелюбный, нейтральный, жесткий)

При решении ученик может ввести диалог:
Он вводит ответ, а ИИ задаает 3 уточняющих вопроса, возможно подсказывает или наоборот путает (в зависимоти от уровня дружелюбности)

ИИ обязательно
- дает обратную связь по ответу ученика
- принимает/отклоняет решение

можно пожаловаться на мнение ИИ
