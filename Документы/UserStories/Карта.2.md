# Карта

- зашел на карту
- видно разблокированную область
- открываешь поинт
    - для освоения решаешь задачи: после решения всех - поинт становится освоенным, получаешь опыт, разблокируются последующие поинты.
- освоив обязательные поинты - область становится освоенной.
- открытие некоторых поинтов - платно.
- каждый поинт может вести на другую карту
- поинты могут сворачивать зависимые поинты, чтобы снижать когнитивную нагрузку. Причем можно сворачивать/разворачивать всю вложенность или вложенность первого уровня. Отображение вложенности может быть заблокировано по разным причинам
- на карте может быть блок с текстом

## ui/ux

### Редактирование

- Поинт
  - Цвет фона
  - Цвет обводки
  - Цвет текста
  - Размер
  - Текст внутри/снаружи
- текст
- Линии
  - Толщина
  - Цвет
  - Изгиб

### Просмотр

- Процент пройденного (в виде обводки)
  - Кол-во всего
  - Кол-во решенных
- Открыть/закрыть вложенность (имеется ввиду вложенные поинты и связи с ними)
- Название
- Описание
- Сложность
  - В виде кол-ва опыта
  - После решения сохраняется, но в скрытом виде
- Статус
  - Заблокировано
  - Решается
  - Решено
- Метки
  - Последняя пройденная тема (Условно где находится пользователь)
  - Закладки
  - Обязательный поинт
  - Тип поинта
    - Карта
    - Лекция
    - Задача
